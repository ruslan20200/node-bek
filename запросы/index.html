    Как показать работу

    1. Нажми GET — получишь список и статус 200.
    2. Введи имя, нажми POST — появится новый пользователь и статус 201. Его ID подставится автоматически.
    3. Измени имя и нажми PUT, затем PATCH — в списке будет новое имя.
    4. Нажми DELETE, затем GET по тому же ID — получишь 404.
    5. Кнопками ошибок покажи статусы 400, 404 и 405.
    Данные хранятся в памяти и сбрасываются после перезапуска сервера. Остановка в терминале: Ctrl+C.
